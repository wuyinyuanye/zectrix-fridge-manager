# 极趣 Note 4（黑白版）· 极趣小冰箱 v2.0 通用完全体固件

基于 **ESP32-S3 + ESP-IDF v5.5**、**原厂 3.7.5 同款 17px 正文 + 29px 标题点阵字库** 与 **纯小智协议（Opus + WebSocket + 设备端冰箱 MCP）** 打造的通用家庭冰箱闭环固件。

- **0 充值、0 API Key、免身份证实名**：默认直连公开免费的 `xiaozhi.me`（屏幕显示 6 位绑定码，输入即用）；
- **支持自家局域网 NAS / 私有小智服务**：手机扫码打开设置页，一行改填局域网地址（例如 `http://192.168.1.100:8003/xiaozhi/ota/`）即可秒连本地服务，**无需改动服务端任何配置**（自动识别并改写容器回环 `127.0.0.1` 地址）。

## 一、 6 页闭环与严格视觉层级

> **视觉原则**：只读展示信息一律**无框纯白**；可点击操作项一律**圆角边框**，且全屏**永远只有 1 个黑底白字（或加粗 `▶`）激活焦点**。闲置时 **0 次刷屏**。

| 页面 | 模式 | 核心能力 |
| --- | --- | --- |
| **Page 0 · 待机小憩封面** | **4bpp 16 灰阶** | 小冰箱表情气泡 + 前 5 样食材（真实存放天数/临期）+ 今晚匹配度最高的一道菜（29px 大字）+ 待买清单；深睡常亮不熄屏 |
| **Page 1 · 冰箱库存** | 1bpp 局刷 | 支持最多 **80 样**食材；**绝不编造保质期**，未设到期的真实显示 `今天放入` / `已放X天`；按 `OK` 弹出：**用它做道菜 / 吃光啦 / 吃光并加采购** |
| **Page 2 · 今日食谱** | 1bpp 局刷 | 实时比对冰箱库存，显示 `✓已有` / `×缺料` 与匹配度；3 个清晰按钮：**开始做菜 / 缺料加采购 / 换一道菜** |
| **Page 3 · 烹饪引导 & 计时** | 1bpp 局刷 | 无框 **29px 原生大字**，底部仅 **1 个全宽黑底按钮**；计时仅静默刷新右上角小胶囊（不触发全屏黑白闪） |
| **Page 4 · 采购清单** | 1bpp 局刷 | 标注缺料/补货来源，短按 `OK` 勾选，底部 **一键放进冰箱**（无多余 NFC 干扰） |
| **Page 5 · 系统与配网** | 1bpp 局刷 | 左侧原生二维码 + 右侧状态 + 4 项控制：**查看语音说明 / 绑定码、开启 AP 配网热点、立即小憩、彻底清屏并关机** |

## 二、 极简三实体键

| 按键 | 短按 | 长按 |
| --- | --- | --- |
| **`UP`（上键）** | **顶部菜单**：选上一个页面；**页面内**：上移一项 / 上一个按钮 / 上一步，在第一项再按上 = 回到顶部菜单；弹窗内 = **一键退出**（语音成功弹窗内 = **一键撤销**） | **长按 0.6 秒**：从任何位置直接回到顶部菜单 |
| **`DOWN`（下键）** | **顶部菜单**：选下一个页面；**页面内**：下移一项 / 下一个按钮 / 下一步 | **长按 3 秒**：进 Page 0 16 灰阶封面并进入省电 Deep Sleep（已做 USB 引脚电平保护，插 USB 绝不瞬醒死循环） |
| **`OK`（确认/语音键）** | **顶部菜单**：进入当前页面；**页面内**：执行当前唯一的黑底焦点项 | **按住不放（≥0.35s）**：**PTT 语音**（同步建立 WebSocket + MCP 握手，松手发送 60ms Opus 音频流，执行后大弹窗回显 `我听到` + `已执行`） |

## 五、 从源码编译（字库与本地私有配置）

1. **生成字库（必需）**：界面使用的 17px / 29px 中文点阵字库来自官方 3.7.5 固件，出于授权原因不随仓库分发。用你自己设备的官方固件镜像生成：
   ```bash
   python3 tools/extract_official_375_fonts.py --firmware <official_3.7.5.bin> --out-dir main/assets
   ```
   缺少字库时 `idf.py build` 会直接报错并提示这条命令。
2. **本地私有默认值（可选）**：复制 `main/local_secrets.h.example` 为 `main/local_secrets.h`，填入自家 Wi-Fi 和小智服务器地址，新刷的设备开机即可联网。该文件已被 `.gitignore` 忽略，不会被提交。不创建它也能用，开机后进入 AP 配网热点，手机扫码配置即可。
3. **AP 配网热点密码**：每台设备首次开机随机生成 8 位密码并保存在 NVS 中，显示在设置页和热点二维码里。
4. **界面预览**：`tools/ui_preview/run.sh` 可在电脑上把所有墨水屏页面渲染成 PNG（需设置 `IDF_PATH`）。
